Étapes à suivre pour générer la grille

Copier le Prompt intelligent

Cliquez sur le bouton ci-dessus pour ouvrir la fenêtre et copier l'intégralité du prompt de configuration APC.

Soumettre le Prompt à votre Intelligence Artificielle

Collez le prompt copié dans ChatGPT, Gemini, Claude ou l'IA de votre choix en y joignant votre sujet d'épreuve pour obtenir le code LaTeX exact.
