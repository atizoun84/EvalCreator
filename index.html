Prompt généré

Sortie : Code LaTeX (Overleaf)
Remplissez les paramètres et cliquez sur "Générer le prompt"

Instructions

  • Remplissez le contexte avec une situation authentique
  • Les indices guident l'IA pour générer des questions pertinentes
  • Les compétences sélectionnées seront évaluées
  • Sortie optimisée pour compilation LaTeX sur Overleaf
  • Copiez-collez le prompt dans votre IA préférée
  • Toutes les données numériques sont dans le support, pas dans les questions
  • Document optimisé pour moins de pages, pas d'espace de réponse
  • Option "PHYSIQUE CHIMIE ET TECHNOLOGIE" génère deux parties A et B
  • Numérotation hiérarchique : 1-1, 1-2, 2-1, 2-2...
  • Bouton poussoir "Sous-questions" pour autoriser 1-1-a, 1-1-b si nécessaire
  • Les questions de la Partie 1 (Mobilisation) doivent être utiles à la Partie 2 (Résolution)
  • Cycle et Discipline s'ajustent automatiquement selon la classe choisie (sauf pour Bachotage, Évaluation formative et Travaux dirigés)
  • Bouton "Numérotation standard" pour insérer automatiquement les n° officiels IGPM (devoirs surveillés / productions scolaires)
  • Le bouton "Numérotation standard" fonctionne en mode poussoir : un 2ᵉ clic désactive et rend les champs à nouveau modifiables
  • En mode IGPM actif, la règle de sous-questions est remplacée par le référentiel officiel (aucune contradiction possible)
  • Quand les sous-questions sont activées, une sous-question peut à son tour être ventilée (i, ii, iii… ou a.1, a.2…) uniquement si nécessaire
  • Un numéro de groupe (ex. "2-", "3-") reste TOUJOURS NU : AUCUN titre, chapeau ou libellé après lui (règle absolue pour tous les types d'épreuves)
  • Sous-questions UNIQUEMENT en lettres (a, b, c…), jamais en chiffres
  • Titres de partie "Mobilisation de ressources" et "Résolution" en gras et soulignés
  • Après "Contexte :", saut de ligne obligatoire avant le texte du contexte
  • Mise en forme d'impression optimisée : marges équilibrées, liste compacte, pas de débordement
